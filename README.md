# Frame Medic · interactive pieces for the Superhive page

The Frame Medic product page on Superhive is one long card in plain HTML. These pages are the interactive parts embedded in it:

- `hero.html`: Blender alone, then Heal This Scene, on three Blender Studio shots (real screen recordings in `media/`)
- `w/heal.html`: Heal This Scene step by step
- `w/fix.html`: the slowdowns found in Singularity 100_0040, with Fix, Undo and Fix All
- `w/ready.html`: Ready Frames, from switch to playback
- `w/shield.html`: Crash Shield holding a Remesh that would freeze Blender
- `w/keys.html`: what happens when you render, save, play or undo
- `w/bench.html`: playback measured on Blender Studio shots
- `w/license.html`: which license fits

`media/ui/` holds real captures of the Frame Medic panel. The older single cards (`compare`, `bench`, `heal`, `fix`, `ready`, `shield`, `safe`, `license` at the root) are no longer embedded.

Frame Medic is a Blender add-on by River Extend: https://framemedic.com
