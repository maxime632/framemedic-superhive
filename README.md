# Frame Medic · interactive pieces for the Superhive page

Small pages embedded in the Frame Medic product page on Superhive:

- `compare.html`: Blender alone vs Heal This Scene, real screen recordings with a before/after slider
- `bench.html`: playback measured on Blender Studio production shots
- `heal.html`: what Heal This Scene does, step by step, on Singularity 100_0040
- `fix.html`: the slowdowns Frame Medic finds and the fix for each
- `ready.html`: Ready Frames, heavy shots played from memory
- `shield.html`: Crash Shield holding a value that would freeze Blender
- `safe.html`: what Frame Medic never touches
- `license.html`: which license fits

Frame Medic is a Blender add-on by River Extend: https://framemedic.com
