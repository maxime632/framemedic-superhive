# Frame Medic · interactive pieces for the Superhive page

`hero.html` is the before/after embedded in the Frame Medic product page on Superhive: Blender alone, then Heal This Scene, on two Blender Studio shots (real screen recordings in `media/`). The rest of the page is plain HTML on Superhive.

The other pages (`compare`, `bench`, `heal`, `fix`, `ready`, `shield`, `safe`, `license`) are the earlier cards, no longer embedded.

Frame Medic is a Blender add-on by River Extend: https://framemedic.com
